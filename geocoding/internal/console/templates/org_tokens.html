Calling the API

Get a token from your IdP with the client-credentials grant, then:

curl -X POST -H "Authorization: Bearer $ACCESS_TOKEN" \
  --data-binary '1 Martin Place Sydney' \
  {{$d.APIBase}}/search

Usage counts against this organisation's daily row quota at its tier. Do not send X-Api-Key as well; a request with both is refused.
